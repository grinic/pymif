pymif.microscope_manager.utils.colors.parse_channel_color(raw: Any, index: int = 0) → str[source]

Convert a vendor-specific channel color to RRGGBB.

This is the single entry point used by the microscope managers, the Zarr writer and the napari viewer. It accepts:

  • None / empty values -> the default palette color for index;

  • integers or integer strings: 24-bit RGB (0 <= v <= 0xFFFFFF, as written by Opera) or signed 32-bit OME RGBA (see ome_color_to_hex());

  • 0x-prefixed hex strings;

  • #AARRGGBB / AARRGGBB (Zeiss) -> alpha dropped;

  • 6-digit hex codes and matplotlib color names (see parse_color()).
